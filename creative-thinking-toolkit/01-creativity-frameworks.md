# 01 · Classic Creativity Frameworks as Prompts

Structured frameworks force *coverage* — they make you (and the model) look at angles you'd otherwise skip. Each one below is a prompt you can paste. Fill the `{placeholders}`.

## 1. SCAMPER

A 7-lens checklist — **S**ubstitute, **C**ombine, **A**dapt, **M**odify, **P**ut to another use, **E**liminate, **R**everse — for systematically transforming something that already exists. Best when you have a product/service/idea and want to reinvent it, not start from scratch.

```
I need ideas for {challenge}. Walk me through SCAMPER one lens at a time.
For each of the 7 lenses — Substitute, Combine, Adapt, Modify, Put to another
use, Eliminate, Reverse — give me 3 concrete ideas specific to {challenge},
so 21 ideas total. After each idea add a one-line "why this could work".
End with the 3 most non-obvious ideas across all lenses.
```

## 2. Six Thinking Hats

Examine a single idea from six deliberately separated modes so no one lens (usually caution) dominates. Great for pressure-testing or enriching *one* concept from every side.

```
Act as a Six Thinking Hats facilitator for this topic: {topic/decision}.
Go through the hats in order, one at a time, with a clear heading for each:
- WHITE: only facts, data, and what we still need to know
- RED: gut feelings and emotional reactions, no justification needed
- BLACK: risks, weaknesses, what could go wrong
- YELLOW: benefits, best-case value, why it could succeed
- GREEN: new ideas, wild alternatives, creative leaps (give 5)
- BLUE: summarize and recommend the next concrete step
```

## 3. Provocation (PO)

De Bono's technique: make a deliberately "impossible" statement (prefixed `PO:`), then instead of judging it, extract *movement* — what principle or angle it opens. Use to shatter an entrenched assumption.

```
Use Edward de Bono's Provocation (PO) technique on this problem: {problem}.
1. Generate 5 deliberately absurd or "impossible" provocations about it,
   each starting with "PO:" (e.g. reverse it, exaggerate it, remove an
   essential element, wishful thinking).
2. For each provocation, do NOT judge it — instead extract "movement":
   what interesting principle, consequence, or angle does it open up?
3. Turn each into 1-2 realistic, actionable ideas for {problem}.
```

## 4. Random Word / Random Stimulus

Inject an unrelated word, force associations to it, then bridge those associations back to the problem. The randomness surfaces connections intent alone never reaches. (This is the "forced connection" move; see also [03 §Forced Connections](03-combinatorial-creativity.md).)

```
We're solving: {problem}. Pick a genuinely random, unrelated noun (an object,
animal, or place — choose one at random and state it first).
1. List 8 attributes/associations of that word.
2. For each association, force a connection to {problem} and derive one idea,
   however strange.
3. Select the 3 most promising ideas and develop them into practical concepts.
Say "again" and I'll want a fresh random word and another round.
```

## 5. Reverse Brainstorming / Inversion

Instead of "how do we succeed?", ask "how would we *guarantee failure*?" — then flip each failure mode into a safeguard. Surfaces blind spots fast. (Inversion is also Charlie Munger's favorite tool.)

```
Use reverse brainstorming for {topic}. List 15 ways to make this problem worse
or guarantee it fails. Then flip each "worse" idea into a constructive idea or
safeguard, phrased as a concrete, testable action or concept.
```

## 6. Worst Possible Idea

Deliberately generate terrible ideas. It lowers the pressure of "being good," loosens thinking, and inverted bad ideas often point straight at good ones. A great warm-up when blocked.

```
Brainstorm intentionally terrible ideas for {topic} to loosen up the thinking.
Expand on each a little, explaining why it's bad. Then take the 5 worst and
invert or exaggerate each into one genuinely useful idea.
```

## 7. First-Principles Thinking

Strip a problem to its undeniable fundamentals — discarding analogy and convention — then rebuild upward from those alone. For breakthrough rethinks, not incremental tweaks. (The neurodivergent-flavored version, [Assumption Breaker](02-neurodivergent-thinking-modes.md#9-assumption-breaker-first-principles), adds a 5-Whys pass.)

```
Analyze {problem} using first-principles thinking. Do not rely on assumptions,
analogies, or how others currently do it.
1. DEFINE: restate the problem precisely.
2. ASSUMPTION AUTOPSY: list every assumption baked into how it's normally framed.
3. FUNDAMENTAL TRUTHS: strip those away — what is verifiably, undeniably true here?
4. REBUILD: using ONLY those truths, derive 3 novel or optimized solutions.
5. CONTRAST: how does each differ from the conventional approach, and what does
   it unlock?
```

## 8. Morphological Analysis (Zwicky Box)

Break a problem into independent parameters, list options for each, then combine across dimensions to generate — and screen — a large configuration space. Best for product/design concepts where the value is in the combinations.

```
Do a morphological analysis for {product/challenge}.
1. Break it into 4-6 independent dimensions/parameters (e.g. form factor,
   material, power source, user, interaction model, business model).
2. For each dimension, list 4-6 distinct options in a table (a morphological matrix).
3. Generate 8 novel combinations by picking one option per dimension — favor
   unexpected but internally coherent combos over safe ones (discard contradictions).
4. Shortlist the 3 most promising configurations and explain why.
Constraints to respect: {constraints}
```

## 9. TRIZ / Contradiction-Driven Ideation

Frame the problem as a *contradiction* (improving X worsens Y), then resolve it with TRIZ's inventive principles. Best for engineering/systems problems with hard trade-offs.

```
Apply TRIZ to {engineering/design/systems problem}.
1. State the core contradiction: "When we improve {parameter A}, it worsens
   {parameter B}."
2. Map A and B to the relevant TRIZ engineering parameters.
3. Suggest 4-5 applicable TRIZ inventive principles (e.g. Segmentation, Taking
   out, Asymmetry, Nesting, "Do it in reverse", Prior action, Self-service).
4. For each principle, propose a concrete solution concept that dissolves the
   contradiction rather than trading off.
```

## 10. Analogical / Cross-Industry Transfer

Borrow a solved mechanism from a distant domain and transfer its *active ingredient* (the underlying principle, not the surface features) to your problem. Distant analogies with shared structure yield the biggest leaps. (Deepened in [02 §Pattern Transfer](02-neurodivergent-thinking-modes.md#4-cross-domain-pattern-transfer) and [03 §Analogical Transfer](03-combinatorial-creativity.md).)

```
Solve {problem} using cross-industry analogy.
1. Abstract the core function we need (state it domain-neutrally, e.g.
   "distribute a scarce resource fairly under changing demand").
2. Name 5 distant domains that solve a structurally similar problem well
   (deliberately far: biology, logistics, gaming, hospitality, finance, ant colonies).
3. For each, describe HOW they solve it — the underlying principle.
4. Transfer and adapt each principle into a concrete idea for {problem}.
5. Highlight the most distant analogy that still maps cleanly.
```

## 11. Creative Constraint Injection

Impose artificial limits (time, budget, materials, medium, style). Constraints paradoxically *boost* originality — they cut off the default path. Use whenever outputs feel generic.

```
I need creative ideas for {challenge}. First impose three tight, arbitrary
constraints (e.g. must cost under {X}, ship in {30 minutes}, use only {3
components}, work with no internet). State them, then generate 10 ideas that
work BECAUSE of those constraints, not despite them.
```
