# BrainStorming

A personal brainstorming space where I come with my agents to explore and ideate on different ideas — for startups, life, research, AI, ML, and science.

This repo is where raw thinking happens. No polished products, just experiments, notes, and explorations.

**[`AGENTS.md`](AGENTS.md)** is the condensed index of everything in this repo — what's built, what's only planned, and when to reuse what. Any coding agent working here (Claude Code, Codex, Cursor) should read it first.

## Tools in here

- **[`creative-thinking-toolkit/`](creative-thinking-toolkit/)** — a curated library of prompts and thinking modes for ideating and researching with AI: classic creativity frameworks, neurodivergent-inspired thinking modes, combinatorial-creativity methods, and LLM-native divergence techniques, plus ready-to-run session recipes. Built to push past the obvious, first-answer ideas.
- **`/ideate` skill** (`.claude/skills/ideate/`) — turns the toolkit into a runnable workflow. Ask Claude to brainstorm, research a space, or stress-test an idea and it drives a full diverge-then-converge session.
